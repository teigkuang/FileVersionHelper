# FVHelper 应用图标设计 Brief（cws_60988486083023874）
主题：FVHelper 文件版本管理器的 Windows 桌面应用图标 / 图形标
商品：无实体商品；核心对象为软件品牌「FVHelper」的图标识别符号
用途：exe 资源图标（.ico，六档 256/128/64/48/32/16）、窗口标题栏与任务栏、后续安装包与文档头图
画幅：1:1 方形；标准主版本 1024×1024 PNG

## 用户输入
- 手绘草图（画布 /user-anchors/fvhelper-icon/source）：两张纵向错位叠放的纸张矩形，每张内部 2–3 条横线代表文字行；右上方一只眼睛（椭圆轮廓 + 中心圆点 + 上方三道放射短线）。
- 用户原话：「结合提供的草图和 exe 软件界面风格设计一个 logo，抽象或者符号化都行」。

## 草图视觉解读（待用户确认）
两张叠放的纸＝同一份文档的多个版本（有先后、有历史）；一只带光芒的眼睛＝软件在「盯着你看 / 扫描发现改动」。
两者合成一个语义：**软件始终在盯着文档的变化**。这就是产品的核心闭环（线下改文件 → 回软件扫描 → 提示是否提交）。

## 界面风格约束（来自 P3 实际界面）
浅色简洁：底色 #F5F6F8、面板 #FFFFFF、分割线 #E6E8EB、主文字 #1F2329、次文字 #8A9099、唯一主色 #3B72F6；微软雅黑 UI；无渐变、无重阴影、无拟物材质。
图标基调：扁平几何、线性／实心结合、单一主色 + 中性色，缩小到 16px 仍能读出「叠页 + 眼」。

## 可见文字
none。App 图标不放文字（16px 下必糊），品牌名 FVHelper 只在文档／界面标题里出现；如需字标另做 3:1 横版，不进图标本体。

## 视觉主张
一个可以被 16 像素看懂的「在看文档的眼睛」：叠页提供「版本」的纵深，眼睛提供「扫描／发现」的动词，两者共享同一线宽与圆角。

## 三个候选方向（并行生成，概念与结构都不同）
1. 叠页 + 眼睛：完全承接草图，两张圆角文档错位叠放，右上角一只实心眼，三道短射线；浅蓝底白页。
2. 眼睛即文档：把眼睛长在纸页负形里——一个圆角方页，页内挖出杏仁形眼窝，瞳孔为主色实心圆；更抽象、更省元素。
3. 极简符号：仅「折角页 + 单眼」两个形体叠合，无横线、无射线，纯主色单色符号，最像系统图标。

## 约束
- 允许延展：圆角半径、线宽、叠页错位角度、眼睛开口方向、底色深浅。
- 禁止：文字、渐变、多重阴影、3D 拟物、水印、多余装饰、写实眼球。
- 小尺寸风险：横线与射线在 32px 以下会消失，需在简化版保留主体轮廓。
