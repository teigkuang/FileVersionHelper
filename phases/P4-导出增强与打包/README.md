## 退出标准

- 另一台干净 Windows 电脑：拷入单文件 → 双击 → 打开含 `.dat` 的目录 → 看历史 → 导出，全程可用
- 单文件 ≤ 80MB（超 100MB 回 `docs\02` 评估）；首启 ≤ 3s
- 安装包 ≤ 50MB，卸载无残留
- A5（含元数据导出 → 另一台电脑继续用）通过
