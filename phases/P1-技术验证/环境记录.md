### 安装过程（可复现）

1. `dotnet-install.ps1 -Channel 10.0` **不可用**（后台运行无产物、长时间无输出，两次后放弃）。
2. 取官方元数据：`https://builds.dotnet.microsoft.com/dotnet/release-metadata/10.0/releases.json`（200，约 1.15 MB）→ latest SDK = `10.0.403`。
3. 下载：`curl.exe -L --retry 3 -o D:\IDE\dotnet-sdk-10.0.403-win-x64.zip https://builds.dotnet.microsoft.com/dotnet/Sdk/10.0.403/dotnet-sdk-10.0.403-win-x64.zip`（286.8 MB，约 1.1 MB/s，4 分 17 秒）。
4. 校验：`Get-FileHash -Algorithm SHA512` 与官方元数据
   `7a114c318fa7f1d9822991b534b2814d0e78386ceda816b371f5141acefe741d87ccb606ede06cadac8f9ac5070e32b708a67bbd1619ff5e5a7858a27874ef48`
   **完全一致**。
5. 解压：`Expand-Archive -LiteralPath <zip> -DestinationPath D:\IDE\dotnet -Force`（exit 0）。
6. 验证：`dotnet --info` / `--list-sdks` / `new list` 均正常。

> 安装包保留在 `D:\IDE\dotnet-sdk-10.0.403-win-x64.zip`（286.8 MB），可作离线重装用；不需要可删。

### 开发期运行注意

本机**系统目录** `C:\Program Files\dotnet` 只有 .NET 6/7/8 运行时，**没有 10**。因此：

- ✅ 编译：`D:\IDE\dotnet\dotnet.exe build ...`（正常）

## 5. 本机工具链坑（务必沿用绕法）

1. **PowerShell 输出的 stdout 会被吞**：多语句 / 带管道 / 长输出时经常 `exited with code 0` 但 stdout 为空或只剩最后一行。
   → 固定做法：命令里把结果 `Set-Content` / `Add-Content` 写进日志文件（如 `D:\IDE\_build.log`），再用 `Read` 读文件。本阶段所有构建、验证输出都走这条路。
2. **单条命令超过约 15 s 会被自动转后台**，需 `TaskOutput` 取结果。
3. **`Start-Process` 启动框架依赖版 exe 失败时**，.NET 会自己打开浏览器跳到 `aka.ms/dotnet-core-applaunch`——会打扰用户桌面，验证时别重复触发。
4. `dotnet new` 的 CLI 输出是本机中文，脚本解析要靠 `DOTNET_CLI_UI_LANGUAGE=en` 固定英文。
5. `dotnet new` 生成的是 **`.slnx`**（不是 `.sln`）。
