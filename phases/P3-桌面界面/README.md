# P3 桌面界面

**阶段目标**：给引擎接一个"学生不看说明书就会用"的界面：加项目（选文件夹）→ 看这个项目的文件 → 扫描后提示提交 → 看 changelist 详情 → 导出当时那一版。
**周期**：28–34 有效工时 ｜ **状态**：**P3 交互项已补完并重发**（勾选提交、四态校验条、导出完成页、三栏拖拽、项目重命名/失效/重新指定、设置项、详情页快捷操作、拖拽文件夹加项目全部落地；版本数据已改为隐藏文件、界面文案统一为"版本信息署名/提交记录/导出（含版本信息）"；39 项测试全绿；单文件 exe 59.17 MB 已覆盖 `releases\`）｜ **前置**：P2 退出标准达成

**浅色简洁**：底色 `#F5F6F8`、面板纯白、1px 分割线 `#E6E8EB`、主文字 `#1F2329`、次文字 `#8A9099`、唯一主色 `#3B72F6`。不做渐变、不堆阴影，用底色差和分割线分层。

## 主界面结构（按用户新语义，非 PM 图原始解读）

```
┌────────────┬─────────────────────────────────┬────────────────────┐
│ 项目    ＋ │ 毕业论文                    重新扫描 │ changelist     3 条 │
│ ────────── │ 上次扫描 · 上次提交 11-06 15:32    │ ──────────────── │
│ 毕业论文    │ ⚠ 检测到 3 个文件有改动——是否提交？│ rev 3 · 改结论与图 │
│ ▓课程论文▓ │ 文件 │状态│大小│修改时间           │ rev 2 · 补第三章   │
│ (空项目示例)│ 论文正文.docx  修改 1.2MB          │ rev 1 · 初次导入   │
│ ＋添加项目  │ [填写修改说明…]       [提交新版本]  │ 点一条→中间显示…  │
└────────────┴─────────────────────────────────┴────────────────────┘
   240px                    自适应(*)                    220px
```

中栏两态：
- **态 A 项目文件视图**（`ProjectPanel`）：项目名 + 上次扫描/上次提交 + 变更提示条 + 文件表（状态着色）+ 底部提交条
- **态 B 提交详情视图**（`CommitPanel`）：`rev N · 说明` + 作者/时间/文件数 + 校验条 + 变更表（A/M/D/R 着色）+ 底部导出条 + "返回文件列表"

详细规范见 `界面稿\主界面布局规范-v0.2.md`。

### 自动化验收脚本（`tools\`）

- `capture-window.ps1` —— `PrintWindow(hwnd,hdc,2)` 截指定窗口（`-ProcessId` 或 `-Hwnd` + `-Out`）。**不要用 `CopyFromScreen`**：前台一被遮挡就抓错窗口。
- `dialog-tool.ps1` —— 按 `ProcessId + Name + ControlType=Window` 找本进程的模态弹窗，可选截图、可选点某个 `AutomationId` 的按钮。
- `choose-folder-dialog.ps1` —— 自动完成系统"选择文件夹"对话框（填路径 + 点确认）。

踩过的坑（写进脚本注释，别再踩）：

1. `AutomationElement::RootElement.FindAll(TreeScope::Children)` **拿不到**本进程的模态子窗口，找弹窗要用 `Descendants`；Win32 消息框（`#32770`）连 UIA 都可能看不见 → 用 `EnumWindows` 按 PID + `GetWindowText` 找。
2. 绝不能用 `$condA & $condB` 拼条件（PowerShell 里 `&` 是调用运算符），要 `New-Object AndCondition(a,b,c)`。
3. 按标题找 `设置` 会先命中顶栏那个叫"设置"的**按钮**（52×27），必须加 `ControlType=Window`。
4. PowerShell 多语句/带管道的长脚本 stdout 常被吞（exit 0 但没输出）→ 每步 `Add-Content` 写日志文件再 `Read`。
