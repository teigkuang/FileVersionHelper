## 1. 一句话语义

**软件管理"多个项目"，每个项目 = 用户选中的一个文件夹。** 左侧是项目列表，中间是"这个项目的文件/或某次提交的详情"，右侧是这个项目的 changelist。

用户线下用 Word/Excel 改完文件，回到软件扫描 → 提示"检测到 N 个文件有改动，是否提交为新版本" → 填说明提交 → 该次提交进入右栏 changelist → 点某条 changelist，中间区切成"那次提交的详情"，并可导出当时那一版的文件或文件夹。

   240px                 *                          220px

## 3. 左栏：项目列表

| 元素 | 行为 |
|---|---|
| 标题"项目" + 右上"＋" | "＋"= `OpenFolderDialog` 选一个**文件夹**，作为新项目加入列表并选中；已加入过的路径去重（选中已有项） |
| 列表条目（三段式） | 第一行 项目名（默认取文件夹名，可后续重命名）／第二行 路径／第三行 上次提交时间或"尚无提交记录" |
| 选中态 | 底色 `#EDF2FE`，无系统蓝框；悬停 `#F7F9FC` |
| 底部提示 | "＋ 添加项目：选择论文文件夹（含 .fvhelper.dat，或全新的空文件夹）" |
| 空态 | 列表为空时中间区显示引导："点右上 ＋ 添加你的第一个论文文件夹" |

一条项目背后就是一个本地文件夹 + 其内的 `.fvhelper.dat`（P2 由 Core 建立/读取）。

## 4. 中栏：两态切换

### 4.1 态 A —— 项目文件视图（`ProjectPanel`）

| 区块 | 内容 |
|---|---|
| 标题行 | 项目名（15px 半粗）+ 副标题"上次扫描（自动/手动） MM-dd HH:mm · 状态"；右上"重新扫描"按钮 |
| 变更提示条（淡黄 `#FFF8E6` / 描边 `#F2E2B5`） | 有改动时出现："检测到 N 个文件有改动（修改 X / 新增 Y / 删除 Z）——是否提交为新版本？"，右侧"查看改动""提交为新版本"两个按钮；无改动时改成淡绿"✓ 与上次提交一致" |
| 文件表 | 列 = 文件(相对路径) / 状态 / 大小 / 修改时间。状态着色：新增 `#2FA36B`、修改 `#E08700`、删除 `#E5484D`、无变化 `#8A9099` |
| 底部提交条 | 左"填写本次修改说明…"输入框 + 右"提交新版本"主按钮（无改动时禁用） |

说明：用户原话是"点击列表项，显示那个项目中的文件在中间区域"，因此这里用**文件表格**（含状态着色）而非 PM 图上的卡片流；**2026-11-06 已拍板就用表格**（D-14），卡片流不再考虑。

**扫描时机**（D-15）：选中项目立即自动扫一次 → 窗口重新获得焦点（从 Word/Excel 切回）自动扫，2 s 去抖，正在看提交详情时不打扰 → 随时可点"重新扫描"。

### 4.2 态 B —— 提交详情视图（`CommitPanel`）

| 区块 | 内容 |
|---|---|
| 标题行 | `rev N · 提交说明`；副标题"作者 X · 时间 · N 个文件"；右上"返回文件列表" |
| 校验条（淡绿 `#EAF7EF` / 描边 `#BFE6CE`） | "✓ 已校验：该版本记录的文件与数据信息一致（文件数、哈希全部匹配）"；不匹配时为红条 + 具体原因（见 `docs\03` 校验口径） |
| 变更表 | 列 = 动作 / 文件 / 大小。动作着色：A 新增绿、M 修改橙、D 删除红、R 重命名/移动蓝 `#3B72F6` |
| 底部导出条 | 左"导出后可把文件夹直接发给别人：对方用本软件打开即可继续查看、编辑并提交。"；右"导出（仅文件）"次按钮 + "导出（含数据信息文件）"主按钮 |

点击右栏某条 changelist 即切入态 B；点"返回文件列表"回态 A。程序内部清空右栏选中时用标志位抑制切换（避免误触）。

## 5. 右栏：changelist

| 元素 | 内容 |
|---|---|
| 标题 | "changelist" + 右侧条数"3 条" |
| 条目（两行） | 第一行 `rev N · 说明`；第二行 时间（`11-06 15:32`）。越往下越早 |
| 排序 | 新→旧（顶端是最新一次提交） |
| 可滚动 | 竖向滚动条；禁用横向滚动 |
| 选中态 | 同上左栏样式 |
| 底部提示 | "点某一条 → 中间显示该次提交的文件与说明，可导出当时的版本" |

## 6. 视觉 token（已落地到 XAML 资源）

| 用途 | 色值 |
|---|---|
| 窗口底色 | `#F5F6F8` |
| 面板底色 | `#FFFFFF` |
| 分割线 | `#E6E8EB` |
| 主文字 | `#1F2329` |

| 成功/新增 | `#2FA36B` |
| 警告/修改 | `#E08700` |
| 危险/删除 | `#E5484D` |
| 字体 | 微软雅黑 UI（回退 Segoe UI）；正文 13px，标题 15px，表头/说明 12px |
| 圆角 | 面板 8 / 条目 6 / 按钮 6 |

已建样式：`NavItemStyle`（左右列表条目）、`FileRowStyle`（表格行）、`GridHeaderStyle`（表头 30px 白底 + 1px 下划线 + 灰字）、`PrimaryButton`（蓝底白字，禁用转 `#DCE3F0`/`#7C85A0`）、`SecondaryButton`（白底 1px 边框）。

原则：一屏一个主色强调；不用阴影堆层次，用底色差 + 1px 分割线；不做渐变。
