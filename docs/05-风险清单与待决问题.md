## 4. P1 实测回填（2026-11-06）

| 风险 | 实测结果 | 状态 |
|---|---|---|
| R-04 文件被占用 | `FileShare.ReadWrite` 共享读**可读**；占用中 `File.Replace` 抛 `IOException`；`FileShare.None` 时连读都失败。`~$*.docx` 锁文件会被枚举到 | **已验证，需对策**：提交前 `FileShare.None` 预检 + 占用清单提示（I-03/I-04/I-09） |
| R-05 路径 >260 | 319 字符路径：建目录 / 写 / 读 / `File.Replace` / 删树**全部 OK**（`LongPathsEnabled=0` 也不影响，.NET 10 自动处理） | **已关闭**：取消"统一加 `\\?\`"方案（I-02） |
| R-08 单文件体积 | **58.83 MB**，发布目录仅 1 个 exe | **已关闭**：不触发 WinForms 回退 |
| R-09 首启解压慢 | 首启 **1330 ms**（含解压到 `%TEMP%\.net`）、二启 **692 ms** | **可接受**；手册注明"首次启动稍慢" |
| R-01 原子写可靠性 | `File.Replace` 目标存在/备份正确；目标不存在须 `File.Move`；只读目标需清属性后重试；跨盘不支持 | **已验证**：写索引分两条路（I-05/I-06） |
| R-13 之后的风险 | 监听事件重复：期望 58 次操作，实测 Changed 45（vs 15），总事件 88 | **已验证**：必须按路径去抖 1 s + 定时兜底（I-08） |
