# tools — 辅助脚本

只放"开发与验证用的工具"，产品代码一律在 `..\app\`。

## 计划中的脚本

| 脚本 | 用途 | 阶段 |
|---|---|---|
| `生成样例.ps1` | 造论文样例目录（含中文名、超长路径、深层嵌套、指定大小文件） | P0/P1 |
| `造长路径.ps1` | 造 >260 字符的目录与文件，用于 V2 验证 | P1 |
| `破坏索引.ps1` | 生成截断/改字节/缺 blob 的仓库，用于损坏恢复测试 | P2 |
| `跑验收.ps1` | 半自动跑 A1–A10 中可脚本化的部分，输出结果到 `phases\P5-测试与发布\验收记录\` | P5 |
| `打包.ps1` | 调 Inno Setup / 7z SFX，输出到 `..\releases\` | P4 |

## 约定

- 脚本用 PowerShell 7（本机 `pwsh` 7.6.4），路径一律绝对路径 + `-LiteralPath`。
- 每个脚本开头写：用途、用法示例、会改动哪些路径、是否可重复执行。
- 破坏性脚本（清理产物、删测试目录）必须在脚本里把目标目录硬编码为 `samples\` 或 `%TEMP%\fvhelper-test\`，不接外部传入的任意路径。
